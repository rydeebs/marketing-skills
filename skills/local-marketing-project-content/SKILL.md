# Project content

## Purpose and inputs

Organize a completed construction or home-service project into a verified source pack for reusable marketing content. Adapt to the user’s actual business; do not assume West Coast Deck is the client.

Start with: Project identifier, available photos/videos, field notes, products used, city, scope, completion date, and customer sharing permissions. Use supplied context first. Ask only for missing facts that block a correct result; mark other gaps and continue.

## Workflow

1. Create a project folder with before, during, after, and selected assets. Preserve originals, use consistent filenames, and identify missing or duplicate media.

2. Build a project fact sheet covering service type, city, materials/products, dimensions when measured, original challenge, work performed, and documented outcome. Mark unknown values instead of estimating them.

3. Connect each factual claim to a field note or responsible team member. Record photo credit and permission boundaries; use a public city-level description instead of a home address.

4. Create an asset plan for a case study, before/after post, short video, profile update, and email snippet. Tailor the angle to each channel without inventing new results.

## Deliverable

Deliver the organized asset index, project fact sheet, missing-input list, and a channel reuse table with angle, assets, draft owner, and status.

## Quality checks

Separate internal project records from public-ready material. Every derived content piece should trace back to the same verified project facts.

## Execution boundary

Use the tools available in the working environment; if access is missing, deliver a usable draft or handoff and state the limitation. Follow the user’s existing authorization and tool policies. Before any external change or communication, confirm the account, destination, and scope; this skill itself grants no authority to publish, send, purchase, or delete. Record confirmed results and stop after at most two retries of a failed write unless the service proves it did not land.
