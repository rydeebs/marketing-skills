# Runway GTM Skills

Claude skills for a go-to-market role at [Runway](https://runwayml.com), covering marketing, sales, partnerships, and community. Each folder in `skills/` contains a `SKILL.md`.

Each skill asks Claude to check current Runway product facts (models, plans, pricing, policy) against runwayml.com or internal docs instead of relying on memory, and to stop for approval before publishing, sending, or spending.

## Install

```bash
cp -R skills/* ~/.claude/skills/
```
